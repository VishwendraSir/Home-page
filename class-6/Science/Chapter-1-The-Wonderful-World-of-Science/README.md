# SCIENCE CENTRE LEARNING HUB — Class 6 Science Chapter 1

**The Wonderful World of Science** — Guided by Vishwendra Sir

## Live student learning page
https://vishwendrasir.github.io/Home-page/class-6/Science/Chapter-1-The-Wonderful-World-of-Science/

## Included in Version 2
- 20 bilingual topic lessons (Hindi / English / Both)
- Learning objectives, expanded study notes, examples, key terms and activities
- Topic-wise MCQ checks and a 20-question chapter assessment
- Browser speech synthesis (no autoplay)
- YouTube URL embed player and YouTube search links
- Local MP4/WebM picker
- Student progress dashboard stored in this browser/device
- PWA manifest, app icon and service-worker cache

## Delivery implementation
The full interactive HTML is gzip-compressed and stored as `book-v2.html.gz.b64`. The `index.html` loader decodes and decompresses it in supported modern browsers. Keep both files in the same folder.

## Important scope notes
- The 20-topic material is an expanded learning edition; teacher review against the master notes is recommended before treating it as a final textbook.
- YouTube requires internet; paste a teacher-approved URL to play it inside the lesson. Local videos are selected from the student's device and are not bundled.
- Browser voice depends on device/browser speech voices.
- PWA installation and offline use require HTTPS. Open the page once while online so the service worker can cache the app shell and compressed lesson.
- Progress is local to one browser/device. Login, cloud sync, payments and downloadable certificates are not enabled in this release.
