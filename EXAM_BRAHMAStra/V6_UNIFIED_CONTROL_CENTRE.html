  1. Import question bank → Standardizer
  2. Normalize and export JSON → Master Database
  3. Run syllabus gap report → Syllabus Coverage
  4. Review structure → QC & Analytics
  5. Verify source and answer manually → Source Verification
  6. Resolve concept duplicates → Duplicate Audit
  7. Edit/review → Review Editor
