SCIENCE CENTRE LEARNING HUB — Champion Home Page
=================================================

Main file: index.html

Upload to GitHub Pages from Android:
1. Open https://github.com/VishwendraSir/Bhakti-pannel-
2. Tap Code -> Add file -> Upload files.
3. Upload this index.html to the repository root.
4. If prompted, replace the existing index.html.
5. Enter a commit message and tap Commit changes.
6. Open Settings -> Pages. Set Source to "Deploy from a branch", Branch to "main", folder to "/ (root)", then Save.
7. After GitHub Pages builds, open the live URL shown under Settings -> Pages.
