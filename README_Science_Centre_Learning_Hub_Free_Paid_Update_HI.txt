ANDROID UPLOAD
1. Download and extract the ZIP package.
2. Open https://github.com/VishwendraSir/Home-page
3. Go to main branch -> Add file -> Upload files.
4. Upload index.html and Science_Centre_Learning_Hub_Complete_Workspace.html to repository root. Upload the JSON/CSV files too if you want the source map and schema stored in the repository.
5. Commit to main only after checking the files. The ZIP includes the existing homepage backup link in the report; preserve index.backup-2026-10-25.html already present in GitHub.
6. Open Settings -> Pages, confirm the selected branch is main and folder is /(root), then wait for GitHub's deployment status.
7. Test both URLs on the phone. A commit is not a full browser test.

PYQ AUTHENTICITY RULE
An item can be called an authentic PYQ only when its exam, year/session, question/paper reference, official source URL and answer-key verification are recorded. Original practice questions must be labelled as original/PYQ-pattern, not genuine PYQs. Review copyright conditions before embedding full papers in any paid product.
