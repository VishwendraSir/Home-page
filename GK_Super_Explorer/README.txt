GK Super Explorer Hybrid PWA

Upload index.html, manifest.webmanifest, sw.js and icon.svg together to the same HTTPS folder (for example GitHub Pages). Open index.html and use the browser menu > Add to Home Screen / Install App. First visit needs internet so the app shell can be cached; subsequent launch can work offline.

The existing embedded question bank and quiz logic are retained. The app includes the redesigned responsive dashboard, class/question practice, voice controls, five themes, daily practice, local progress/rewards, offline app-shell cache and local backup tools.

Limitations: AI Tutor is a local question-bank explanation helper, not a connected generative AI service. Leaderboard is local-device only. Admin tools are demo/local and not secure production authentication. Online multi-student accounts, cloud ranking and live AI require a secure backend.
