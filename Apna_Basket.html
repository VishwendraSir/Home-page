☁️ V12 Firebase Cloud Sync & Security

अब Firebase Console से Copy किया हुआ पूरा JavaScript Config सीधे पेस्ट करें; JSON भी स्वीकार होगा। Admin/Customer login और Firestore sync के लिए Firebase setup व सुरक्षित Rules जरूरी हैं।

Firebase Console के Config बॉक्स से Copy करें और यहाँ सीधे Paste करें। // comment और const firebaseConfig भी अब स्वीकार हैं।
Firebase: Not connected • Local mode active

Admin login उसी Firebase Authentication account से करें जिसका UID users document में role=admin है। बिना Email/Password Connect करने पर Anonymous Customer session बनेगा। Google Login Customer के लिए है। Password browser में save नहीं होता।

Firebase setup instructions & Rules
  1. Firebase Console में project बनाएं और Web App register करें।
  2. Authentication → Sign-in method में Email/Password और Anonymous enable करें।
  3. Firestore Database बनाएं।
  4. Admin user बनाकर उसका UID नीचे दिए Rules में ADMIN_UID की जगह रखें।
  5. Firebase Project settings → Your apps → SDK setup → Config से पूरा snippet Copy करके ऊपर पेस्ट करें।
  6. Firestore users document में Admin की role value lowercase admin रखें।
V11 Order Schema: id, userId, name, phone, address, pincode, status, subtotalPaise, deliveryFeePaise, totalPaise, items[], payment, date (Firestore Timestamp), note, discountPaise and optional couponCode. Rules must explicitly allow these fields. Do not publish permissive starter rules.

Security boundary: Browser में चलने वाला Admin transaction trusted server नहीं है। Real production में Cloud Functions/Cloud Run से price, stock, coupon और delivery fee validate कराएँ। नीचे दी गई Rules UID/role/ownership और write access सीमित करती हैं; वे payment settlement या पूर्ण server-side pricing validation का विकल्प नहीं हैं।
